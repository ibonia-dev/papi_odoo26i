A native Odoo payment provider

Papi appears next to the other payment providers of Odoo. Your customers select Papi at checkout, pay on the secure Papi page with the instrument of their choice, and come back to your website. Orders are confirmed automatically once Papi has confirmed the payment.

  • eCommerce checkout, customer portal invoices, online quotations and payment links
  • "Pay with Papi" button on invoices and sales orders: a back-office operator can collect a payment on behalf of the customer
  • MVola, Orange Money, Airtel Money and card (BRED), chosen on the Papi page
  • Signed server-to-server notifications (HMAC-SHA256), replay protection
  • Status always re-checked with the Papi API: a customer return is never trusted as a proof of payment
  • Idempotent processing: repeated notifications never confirm an order twice
  • Automatic catch-up of lost notifications and expired payment links
  • Papi reference, status, instrument, failure reason and error code visible on each transaction
  • "Test the Connection" and "Check Papi Status" buttons for diagnosis
  • Secrets restricted to administrators and never written to the logs

Requirements / Configuration requise

HostingOdoo.sh or on-premise. Odoo Online (SaaS) is not supported: it does not allow third-party modules
Python / PostgreSQLPython 3.10+ and the PostgreSQL version supported by your Odoo; only the standard Odoo dependencies (requests)
Odoo appsaccount_payment (installed automatically); website_sale for the eCommerce checkout; sale for quotations and sales orders
CurrencyMGA (Ariary) enabled, with an MGA pricelist for eCommerce; minimum amount 300 MGA
Public URLweb.base.url set to your public HTTPS address, so Papi can reach /payment/papi/webhook. Behind a reverse proxy: proxy_mode = True and keep the X-Papi-Signature header
NetworkInbound HTTPS to the webhook (no IP filtering); outbound HTTPS (443) to app.papi.mg
Papi accountA verified Papi shop with its API key and notification signing secret (sign up)
Papi has no sandbox. In Odoo "Test" mode, Mobile Money payments are real. Use the Test Mode of your Papi shop with the test card to test without moving money.

Up and running in four steps

  1. Install the package matching your Odoo version (payment_papi; the sales-order bridge payment_papi_sale comes with it).
  2. Copy two secrets from dashboard.papi.mg (shop → Developer tab): the API key and the notification signing secret.
  3. Paste them in Accounting → Configuration → Payment Providers → Papi, pick a bank journal, then click Test the Connection.
  4. Switch the provider to Enabled. Papi now shows up at checkout and on invoices.
